# 首页搜索与设置收纳设计

## 目标

将首页现有的主题模式和显示模式控件收纳到设置按钮的紧凑浮层中，把释放出的页头空间用于常驻搜索框。搜索需要支持定位页面分类或分组，也需要支持直接打开站点。

## 视觉结构

- 保留现有品牌标题、分类数量与链接数量，不改变首页主体卡片结构。
- 用一条横向搜索框和一个固定尺寸的齿轮图标按钮替换页头右侧现有的两组胶囊控件。
- 搜索框沿用现有白色表面、细边框、圆角、克制阴影和蓝色焦点色。
- 搜索结果下拉紧贴输入框，分为“页面位置”和“网站”两组。
- 设置按钮展开贴近按钮的紧凑浮层，不使用居中大弹窗。
- 设置浮层保留两组分段控件：“主题：系统 / 日间 / 夜间”和“显示：简洁 / 详细”。
- 桌面端搜索框占据页头释放出的主要空间；移动端搜索框与设置按钮位于品牌标题下方，搜索框弹性填充剩余宽度。

## 搜索范围与结果

搜索索引在首页内容加载后由现有 galleries 数据生成：

- 分类标题：结果类型为页面位置，选择后滚动到分类标题。
- 分组标题：结果类型为页面位置，选择后滚动到具体分组标题。
- 网站名称和描述：结果类型为网站，选择后在新标签页打开网站。

搜索忽略首尾空格和英文大小写。结果优先匹配标题，再匹配描述与所属分类；结果数量受限，避免下拉层变成完整目录。

页面位置结果展示标题与所属层级；网站结果展示图标、网站名称和所属分类。无匹配时显示简短空状态，内容加载期间搜索框不可用。

## 交互

- 输入内容后实时展示结果。
- 上下方向键移动当前结果，Enter 选择当前结果，Escape 关闭结果列表。
- 点击页面位置结果后平滑滚动，并对目标标题所在区域进行短暂高亮。
- 点击网站结果后在新标签页打开，并关闭搜索结果。
- 点击页面空白处关闭搜索结果或设置浮层。
- 搜索结果和设置浮层互斥，同一时间只展示一个。
- 设置变更立即生效，并继续通过现有 Pinia store 与 localStorage 持久化。

## 组件边界

- `HomePage.vue`：提供搜索索引、协调页内滚动和短暂高亮、处理网站打开。
- `HomeHeader.vue`：负责页头布局、搜索与设置浮层的互斥和点击外部关闭。
- `HomeSearch.vue`：负责输入、结果分组、键盘导航和结果选择。
- `HomeSettingsPopover.vue`：负责主题模式和显示模式的紧凑设置界面。
- `HomeCategorySection.vue`：为分类和分组节点提供稳定 DOM 标识与高亮状态。
- `homeViewModel.ts`：提供稳定标识、搜索索引生成和查询函数，保持纯函数以便单元测试。

## 异常与边界

- 内容尚未加载或加载失败时不生成可选择的旧索引。
- 空输入不展示结果列表。
- 相同名称的网站使用 URL 和所在层级保持结果可区分。
- 目标节点不存在时仅关闭搜索结果，不抛出用户可见错误。
- 尊重 `prefers-reduced-motion`，在减少动态效果时关闭平滑滚动和高亮动画。

## 验证

- 单元验证搜索索引生成、中文与英文匹配、标题优先级、空查询和结果上限。
- 浏览器验证键盘导航、页内跳转、外链打开、浮层互斥和点击外部关闭。
- 在桌面与移动端检查布局，覆盖日间、夜间与系统主题。
- 运行生产构建，确认 Vue 和 TypeScript 编译通过。

## 非目标

- 不做全站路由搜索。
- 不搜索榜单新闻或通知横幅。
- 不在输入时过滤或隐藏首页内容。
- 不引入远程搜索服务、模糊搜索依赖或新的全局状态。
